# 2.1.4 Ollama и локальные модели

### Подключение языковой модели к PHP

Иногда языковую модель нужно запускать не через облачный сервис, а прямо на своём компьютере или сервере.

Это важно, когда проект работает с закрытыми данными, используется внутри компании, должен запускаться без интернета или требует снижения расходов на запросы к внешним сервисам.

Один из популярных инструментов для локального запуска моделей – Ollama. Он позволяет установить модель на свою машину и обращаться к ней через локальный HTTP-интерфейс.

Документация Ollama:\
[https://ollama.com/docs](https://ollama.com/docs)

### Запуск модели

Например, модель Llama 3 можно запустить так:

```bash
ollama run llama3
```

После этого модель будет доступна локально.

### Вариант на чистом PHP

К локальной модели можно обратиться из PHP через обычный HTTP-запрос.

```php
$response = $client->post('http://localhost:11434/api/generate', [
    'json' => [
        'model' => 'llama3',
        'prompt' => 'Explain embeddings simply',
        'stream' => false
    ]
]);
```

В этом примере запрос отправляется не во внешний API, а на локальный адрес `localhost`.\
Это значит, что модель работает на той же машине или внутри вашей локальной инфраструктуры.

### Вариант на Laravel

В Laravel тот же запрос можно записать немного короче:

```php
$response = Http::post('http://localhost:11434/api/generate', [
    'model' => 'llama3',
    'prompt' => 'Explain embeddings simply',
    'stream' => false
]);

$data = $response->json();
```

Laravel берёт на себя отправку запроса и удобное преобразование ответа в массив.

### Особенности локальных моделей

Локальный запуск даёт больше контроля над данными и инфраструктурой.

Такой подход полезен для:

* работы с приватными данными
* корпоративных систем
* автономного режима без интернета
* снижения стоимости при большом количестве запросов

Но у локальных моделей есть и ограничения:

* качество ответа может быть ниже, чем у облачных моделей
* нужны ресурсы процессора или видеокарты
* сложнее масштабировать систему
* нужно самостоятельно следить за установкой, обновлениями и производительностью модели
