# 2.1 Подключение LLM к PHP

Как построить универсальный AI-клиент для современных PHP-приложений.

Подключение LLM к PHP на первый взгляд выглядит как обычная интеграция внешнего API. Но очень быстро становится понятно, что это не просто "ещё один HTTP сервис". Это новый слой системы, который ведёт себя как вероятностная вычислительная машина, а не как детерминированный бэкенд.

Поэтому задача этой главы – перейти от простого API-клиента к пониманию архитектуры AI-интеграции в продакшене.
