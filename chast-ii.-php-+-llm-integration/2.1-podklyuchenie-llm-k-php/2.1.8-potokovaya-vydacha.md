# 2.1.8 Потоковая выдача

### Streaming responses

Языковая модель может возвращать ответ не целиком сразу, а постепенно — по мере генерации текста.

Например:

```
→ Hello
→ Hello world
→ Hello world!
```

Пользователь начинает видеть результат ещё до того, как модель завершит полный ответ.

### **Почему это важно**

Такой подход значительно улучшает пользовательский опыт.

Когда ответ появляется постепенно, система кажется быстрее и "живее", даже если общее время генерации почти не меняется.

### Математика задержки

Общее время ответа можно описать так:

$$
T = T_{prompt} + N \cdot T_{token}
$$

Где:

* $$T_{prompt}$$  — время обработки запроса
* $$T_{token}$$ — время генерации одного токена
* $$N$$ — количество токенов в ответе.

Потоковая выдача не уменьшает полное время генерации, но снижает ощущаемую задержку, потому что пользователь начинает получать ответ раньше.

### Потоковая выдача в Laravel

```php
$response = Http::withToken(env('OPENAI_API_KEY'))
    ->withOptions([
        'stream' => true,
    ])
    ->post('https://api.openai.com/v1/chat/completions', [
        'model' => 'gpt-4.1-mini',
        'stream' => true,
        'messages' => [
            ['role' => 'user', 'content' => 'Explain transformers']
        ]
    ]);
```

В этом примере приложение включает потоковый режим (`'stream' => true`). Модель начинает отправлять части ответа сразу по мере генерации, а не ждёт завершения всего текста.
