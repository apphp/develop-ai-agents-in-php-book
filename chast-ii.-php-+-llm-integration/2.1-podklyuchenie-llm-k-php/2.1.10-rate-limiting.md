# 2.1.10 Rate limiting

#### Ограничение количества запросов

Интерфейсы больших языковых моделей обычно ограничивают количество обращений к сервису (rate limiting). Чаще всего используются два вида ограничений:

* **RPM** – (requests per minute) количество запросов в минуту
* **TPM** – (tokens per minute) количество токенов в минуту

Стоимость работы с моделью обычно зависит от количества входных и выходных токенов:

$$
Cost ∝ InputTokens + OutputTokens
$$

То есть чем больше текста передаётся в модель и чем больше текста она возвращает, тем выше итоговая стоимость.

Также на стоимость влияет размер окна контекста. Чем больше данных модель может принять за один запрос, тем дороже может быть обработка такого запроса.

### **Примеры работы с** rate limiting

#### **Ограничение запросов в Laravel через промежуточный обработчик**

```php
RateLimiter::for('ai', function () {
    return Limit::perMinute(60);
});
```
