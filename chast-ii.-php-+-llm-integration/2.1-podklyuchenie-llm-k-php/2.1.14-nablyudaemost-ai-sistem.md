# 2.1.14 Наблюдаемость AI-систем

Наблюдаемость ([observability](../../vvedenie/glossarii.md#observability)) AI-систем – это способность получать полную картину того, как работает модель и что происходит во время обработки запросов. Искусственный интеллект нельзя контролировать так же, как обычный программный интерфейс, поэтому для него требуется более широкий набор метрик.

Важно отслеживать время ответа, количество используемых токенов, стоимость запросов, ошибки, повторные попытки выполнения запросов, сбои поставщика модели и случаи, когда модель выдаёт недостоверную или выдуманную информацию.

Основная сложность наблюдаемости AI-систем заключается в том, что качество ответа трудно измерить объективно. Если для обычного API результат чаще всего однозначно правильный или неправильный, то полезность ответа AI во многом зависит от контекста и ожиданий пользователя.

В Laravel для реализации наблюдаемости можно использовать журналирование:

```php
Log::info('AI request', [
    'tokens' => $tokens,
    'latency' => $latency,
]);
```

В этом примере в журнал записываются данные о количестве использованных токенов и времени обработки запроса, что помогает анализировать работу AI-сервиса и выявлять возможные проблемы.
