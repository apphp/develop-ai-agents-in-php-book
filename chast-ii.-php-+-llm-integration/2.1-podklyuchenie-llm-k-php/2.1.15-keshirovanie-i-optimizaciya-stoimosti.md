# 2.1.15 Кэширование и оптимизация стоимости

**2.1.15 Кэширование и оптимизация затрат**

Одним из наиболее эффективных способов снижения затрат при работе с AI-системами является кэширование. Его основная идея заключается в том, чтобы не выполнять повторную обработку запросов, результаты которых уже были получены ранее.

Существует несколько подходов к организации кэширования. Наиболее простой вариант – использование хеша запроса (_prompt hashing_), когда для каждого текста запроса вычисляется уникальный идентификатор и по нему сохраняется ответ. Более сложный подход – семантическое кэширование (_semantic caching_), позволяющее находить ранее сохранённые ответы не только для одинаковых, но и для схожих по смыслу запросов. Также применяется поиск по векторным представлениям текста (_embedding-based lookup_), при котором система сравнивает эмбеддинги запросов и использует уже имеющиеся результаты для близких по содержанию обращений.

Основная цель кэширования заключается в снижении стоимости работы AI-сервисов. Стоимость напрямую зависит от количества обработанных токенов и числа обращений к модели. Поэтому её можно представить следующим образом:

$$
\text{Стоимость} \propto \text{Токены} + \text{Количество запросов}
$$

Следовательно, уменьшение количества токенов и числа вызовов модели позволяет существенно сократить расходы и повысить производительность приложения.

В Laravel кэширование ответа можно реализовать следующим образом:

```php
$key = md5($prompt);

return Cache::remember($key, 3600, function () use ($prompt) {
    return $this->provider->generate($prompt);
});
```

В данном примере создаётся уникальный ключ на основе текста запроса. Если ответ уже сохранён в кэше, он возвращается сразу без обращения к модели. Если записи нет, запрос отправляется модели, а полученный результат сохраняется в кэше на один час для последующего использования. Это позволяет уменьшить количество повторных вызовов AI-сервиса и снизить затраты на его эксплуатацию.
