# 2.1.2 OpenAI API

### Подключение языковой модели к PHP

Подключить языковую модель к PHP можно буквально в несколько строк кода.

Документация OpenAI API:\
[https://platform.openai.com/docs](https://platform.openai.com/docs)

Раздел с Chat Completions API:\
[https://developers.openai.com/api/docs/actions/introduction](https://developers.openai.com/api/docs/actions/introduction)

### Вариант на чистом PHP

Один из популярных способов – использовать библиотеку Guzzle для отправки HTTP-запросов.

Код создаёт клиент, отправляет запрос в OpenAI API и получает ответ модели.

```php
use GuzzleHttp\Client;

$client = new Client();

$response = $client->post('https://api.openai.com/v1/chat/completions', [
    'headers' => [
        'Authorization' => 'Bearer ' . getenv('OPENAI_API_KEY'),
        'Content-Type' => 'application/json',
    ],
    'json' => [
        'model' => 'gpt-4.1-mini',
        'messages' => [
            ['role' => 'user', 'content' => 'Explain transformers simply']
        ]
    ]
]);

$data = json_decode($response->getBody()->getContents(), true);

echo $data['choices'][0]['message']['content'];
```

В этом примере:

* создаётся HTTP-клиент
* запрос отправляется в OpenAI API
* модель получает сообщение пользователя
* ответ преобразуется из JSON
* итоговый текст выводится на экран

### Вариант на Laravel

Laravel делает интеграцию заметно проще благодаря встроенному HTTP-клиенту.

```php
use Illuminate\Support\Facades\Http;

$response = Http::withToken(env('OPENAI_API_KEY'))
    ->post('https://api.openai.com/v1/chat/completions', [
        'model' => 'gpt-4.1-mini',
        'messages' => [
            ['role' => 'user', 'content' => 'Explain transformers simply']
        ]
    ]);

$result = $response->json();

echo $result['choices'][0]['message']['content'];
```

Здесь большая часть технической работы уже скрыта внутри Laravel, поэтому код получается короче и чище.

### Особенности OpenAI API

OpenAI API построен вокруг диалогового интерфейса: приложение отправляет сообщения, а модель отвечает на них.

Также API поддерживает:

* оплату по количеству токенов
* потоковую передачу ответа в реальном времени
* высокую стабильность работы
* удобную интеграцию практически с любым языком программирования
