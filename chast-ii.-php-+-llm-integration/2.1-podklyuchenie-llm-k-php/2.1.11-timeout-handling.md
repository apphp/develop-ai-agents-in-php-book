# 2.1.11 Timeout handling

### Обработка таймаутов

Если не задавать ограничения по времени ожидания, приложение может надолго зависнуть при обращении к внешнему сервису. Это особенно важно при работе с интерфейсами больших языковых моделей, где ответ может задерживаться из-за высокой нагрузки или проблем с сетью.

Пример настройки ограничений по времени в PHP:

```php
new Client([
    'timeout' => 30,
    'connect_timeout' => 5
]);
```

Обычно используются несколько видов таймаутов:

* **таймаут подключения** – максимальное время на установление соединения с сервером;
* **таймаут запроса** – максимальное время ожидания полного ответа;
* **таймаут потоковой передачи данных** – ограничение времени при получении ответа частями.

Правильно настроенные таймауты позволяют быстрее обнаруживать проблемы и предотвращают блокировку рабочих процессов из-за долго выполняющихся запросов.

### **Примеры работы с** таймаутами

#### **Пример на PHP**

```php
$client = new Client([
    'timeout' => 30,
    'connect_timeout' => 5,
]);
```

#### **Пример в Laravel**

```php
Http::timeout(30)
    ->connectTimeout(5)
    ->post(...);
```
