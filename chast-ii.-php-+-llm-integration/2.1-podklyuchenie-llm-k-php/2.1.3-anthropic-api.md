# 2.1.3 Anthropic API

### Подключение языковой модели к PHP

Anthropic API позволяет подключать модели Claude к PHP-приложениям практически так же, как и OpenAI API.

Документация Anthropic API:\
[https://docs.anthropic.com](https://docs.anthropic.com/)

Раздел с Messages API:\
[https://docs.anthropic.com/en/api/messages](https://docs.anthropic.com/en/api/messages)

### Вариант на чистом PHP

Для отправки запросов можно использовать библиотеку Guzzle.

```php
$response = $client->post('https://api.anthropic.com/v1/messages', [
    'headers' => [
        'x-api-key' => getenv('ANTHROPIC_API_KEY'),
        'anthropic-version' => '2023-06-01',
    ],
    'json' => [
        'model' => 'claude-sonnet-4-0',
        'max_tokens' => 1000,
        'messages' => [
            ['role' => 'user', 'content' => 'Explain vector databases']
        ]
    ]
]);
```

В этом примере:

* запрос отправляется в Anthropic API
* указывается модель Claude
* задаётся максимальный размер ответа
* пользовательское сообщение передаётся через массив messages

### Вариант на Laravel

Laravel позволяет сделать интеграцию короче и удобнее благодаря встроенному HTTP-клиенту.

```php
$response = Http::withHeaders([
        'x-api-key' => env('ANTHROPIC_API_KEY'),
        'anthropic-version' => '2023-06-01',
    ])
    ->post('https://api.anthropic.com/v1/messages', [
        'model' => 'claude-sonnet-4-0',
        'max_tokens' => 1000,
        'messages' => [
            ['role' => 'user', 'content' => 'Explain vector databases']
        ]
    ]);

$data = $response->json();
```

Здесь Laravel автоматически упрощает работу с HTTP-запросами и обработкой JSON-ответов.

### Особенности Anthropic API

Anthropic API использует строгую структуру сообщений, где все запросы строятся вокруг массива messages.

Также API отличается:

* хорошей работой с длинным контекстом
* высокой стабильностью при длинных диалогах
* сильным акцентом на безопасность и ограничения модели
* удобной обработкой больших текстов и документов
