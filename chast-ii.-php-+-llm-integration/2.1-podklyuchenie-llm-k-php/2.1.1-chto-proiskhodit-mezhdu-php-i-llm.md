# 2.1.1 Что происходит между PHP и LLM

С точки зрения PHP всё выглядит просто:

```
PHP → HTTP request → LLM → response
```

Но внутри LLM происходит совсем другая модель вычислений.

Модель не “думает”, она вычисляет распределение вероятностей следующего токена:

$$
P(token_n | token_1, ..., token_{n-1})
$$

Каждый следующий токен выбирается из распределения.

Упрощённо:

```
"Explain transformers"
→ ["in", "simply", "like", "this"]
```

И модель выбирает наиболее вероятное продолжение.

#### Внутренний pipeline

```
Input → Tokenization → Embeddings → Transformer Layers → Attention → Sampling → Output
```

Это важно понимать, потому что:

* ответы не детерминированы;
* latency нестабилен;
* возможны ошибки формата;
* результат зависит от sampling.
