# 2.3.4 Версионирование промптов

### Как происходит версифицирование

Промпты в системах искусственного интеллекта постоянно развиваются и дорабатываются. Даже небольшие изменения в формулировках могут заметно повлиять на качество и стабильность результатов.

Например, на разных этапах развития системы один и тот же промпт может выглядеть следующим образом.

**Версия 1**

<pre><code><strong>Определи настроение клиента.
</strong></code></pre>

**Версия 2**

```
Определи настроение клиента.

Используй категории:
positive,
neutral,
negative.
```

**Версия 3**

```
Определи настроение клиента.

Верни результат строго в формате JSON.
```

На первый взгляд изменения могут показаться незначительными. Однако для языковой модели каждая новая инструкция способна изменить структуру ответа, точность классификации и общее качество работы системы.

### **Почему необходимо отслеживать изменения**

Если разработчики не сохраняют историю изменений, со временем становится сложно ответить на важные вопросы:

* какой вариант промпта используется сейчас
* после какого изменения качество улучшилось или ухудшилось
* как вернуть предыдущую рабочую версию
* какой промпт использовался во время конкретного тестирования или эксперимента

Поэтому промпты рекомендуется хранить в системе контроля версий так же, как и программный код.

Например:

```
prompts/
  sentiment/
    v1.txt
    v2.txt
    v3.txt
```

или

```
prompts/
  sentiment.txt
```

Во втором случае вся история изменений хранится в Git и доступна через журнал изменений.

### **Промпт как программный код**

В современных AI-системах промпт следует рассматривать как полноценный элемент программного продукта.

Как и обычный код, он должен:

* храниться в системе контроля версий
* проходить проверку перед внедрением
* иметь понятную историю изменений
* участвовать в тестировании
* поддерживать возможность отката к предыдущей версии

Такой подход позволяет контролировать качество работы модели, упрощает сопровождение системы и делает процесс разработки более предсказуемым и управляемым.
