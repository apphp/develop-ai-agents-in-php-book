# 2.3 Архитектура промптов

На ранних этапах знакомства с LLM большинство разработчиков воспринимают промпт как обычную строку.

```php
$prompt = "Ответь на вопрос пользователя";
```

Этого достаточно для экспериментов, прототипов и pet-проектов.

Но после выхода в продакшн всё быстро меняется.

Появляются десятки сценариев использования модели. Над промптами начинают работать несколько разработчиков. Возникает необходимость проводить A/B-тесты, отслеживать деградацию качества ответов, контролировать стоимость запросов и управлять версиями инструкций.

В этот момент промпт перестаёт быть строкой.

Он становится частью архитектуры системы.

Современные AI-приложения содержат сотни промптов. Многие компании управляют ими так же, как исходным кодом, API-контрактами или схемами баз данных.

Поэтому сегодня всё чаще используется термин Prompt Architecture – архитектура проектирования, хранения, тестирования и эксплуатации промптов.
