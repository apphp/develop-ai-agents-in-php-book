## Экосистема AI-агентов в PHP

### От вызова модели к агентным платформам

Первые PHP-приложения с искусственным интеллектом были предельно простыми. Разработчик отправлял запрос в модель через HTTP API, получал ответ и отображал его пользователю.

Типичный код выглядел следующим образом:

php $client = OpenAI::client($apiKey); $response = $client->responses()->create(\[ 'model' => 'gpt-5', 'input' => 'Проанализируй сообщение клиента' ]);

Такой подход отлично подходит для первых экспериментов. Однако по мере усложнения системы появляются новые требования:

* работа с несколькими моделями;
* структурированный вывод;
* потоковая генерация;
* вызов внешних инструментов;
* память;
* поиск по документам;
* оркестрация агентов;
* мониторинг и трассировка.

В результате возникает необходимость в более высокоуровневых библиотеках и фреймворках.

Сегодня экосистему PHP для разработки AI-агентов можно условно разделить на три уровня:

1. AI SDK.
2. Agent Frameworks.
3. Agent Platforms.

Каждый следующий уровень абстрагирует разработчика от все большего количества инфраструктурных задач.

## AI SDK

AI SDK представляют собой фундаментальный слой экосистемы.

Их задача – обеспечить удобное взаимодействие с моделями.

Они не пытаются управлять агентами или workflow. Их ответственность ограничивается вызовом модели и обработкой результата.

***

## Agent Frameworks

Если AI SDK отвечают за работу с моделями, то Agent Frameworks поднимают уровень абстракции выше.

Они позволяют создавать полноценных AI-агентов.

Агент обычно включает:

* системные инструкции;
* память;
* инструменты;
* управление контекстом;
* механизм принятия решений.

Именно этот слой сегодня развивается наиболее активно.

## Agent Platforms

Когда количество агентов начинает расти, возникает новая проблема.

Необходимо управлять уже не отдельными агентами, а всей агентной инфраструктурой.

Появляются задачи:

* маршрутизации запросов;
* координации агентов;
* мониторинга;
* тестирования;
* оценки качества ответов;
* управления памятью.

Для решения подобных задач появились Agent Platforms.

***

### PromptlyAgent

PromptlyAgent ориентирован на построение сложных агентных систем.

Основной акцент делается на:

* визуальную оркестрацию;
* многоагентные workflow;
* интеграцию инструментов;
* управление агентами.

По сути это шаг от программирования отдельных агентов к управлению целой экосистемой интеллектуальных сервисов.

***

### Vizra ADK

Vizra ADK представляет собой Agent Development Kit для Laravel.

Он помогает организовать полный жизненный цикл агента:

* разработку;
* тестирование;
* наблюдаемость;
* память;
* workflow;
* взаимодействие подагентов.

По своей идеологии Vizra ADK напоминает современные платформы разработки агентов из экосистем OpenAI и Google.

## Сквозной пример

Вернемся к нашему проекту поддержки клиентов.

Представим письмо:

> "Я уже неделю жду возврат денег. Никто не отвечает."

На разных уровнях экосистемы решение будет выглядеть по-разному.

Использование OpenAI PHP:

php $response = $client->responses()->create(\[ 'model' => 'gpt-5', 'input' => $message ]);

Использование Prism:

php $result = Prism::text() ->using('openai', 'gpt-5') ->withPrompt($message) ->generate();

Использование Neuron AI:

php $agent->run($message);

Использование Agent Platform:

text Ticket Agent ↓ Sentiment Agent ↓ CRM Agent ↓ Reply Agent ↓ Human Operator

Каждый следующий уровень снимает с разработчика часть инфраструктурных задач.

## Будущее экосистемы

Интересно наблюдать, что PHP сегодня проходит примерно тот же путь, который Python прошел в период с 2023 по 2025 год.

Сначала появились SDK для работы с моделями.

Затем возникли библиотеки для tools и RAG.

После этого начали активно развиваться агентные фреймворки.

Следующим этапом стали многоагентные системы и платформы управления агентами.

Эволюцию можно представить следующим образом:

text OpenAI SDK ↓ Prism ↓ Agent Frameworks ↓ Workflows ↓ Multi-Agent Systems ↓ Agent Platforms

Вероятнее всего, в ближайшие годы именно агентные платформы станут стандартным способом разработки сложных AI-приложений.

Отдельные запросы к модели постепенно будут скрываться внутри более высокоуровневых компонентов, а внимание разработчиков сместится к проектированию агентов, workflow и интеллектуальных бизнес-процессов.

## Итоги

Экосистема AI-разработки в PHP уже давно вышла за пределы простых HTTP-вызовов к моделям.

Сегодня разработчик может выбрать инструмент практически для любого уровня сложности:

* OpenAI PHP и Prism для интеграции моделей;
* Neuron AI, LarAgent, PapiAI и Atlas для создания агентов;
* PromptlyAgent и Vizra ADK для построения масштабных агентных платформ.

Для большинства современных проектов путь развития выглядит одинаково: сначала появляется интеграция с LLM, затем инструменты и структурированный вывод, после чего система постепенно эволюционирует в сеть взаимодействующих AI-агентов.

Именно поэтому понимание всей экосистемы становится важным навыком современного бэкенд-инженера, работающего с искусственным интеллектом.
