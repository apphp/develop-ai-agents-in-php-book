# 1.3.5 Temperature, top-p и sampling

Если модель всегда будет выбирать только самый вероятный токен, её ответы быстро станут слишком однообразными и предсказуемыми.

Чтобы сделать генерацию более гибкой, используются специальные стратегии сэмплирования (sampling strategies) – механизмы выбора следующего токена.

### Температура (temperature)

Температура управляет уровнем случайности в ответах модели.

Низкая температура делает ответы более стабильными и предсказуемыми.

```
Temperature = 0.1
→ более детерминированный ответ
```

Высокая температура, наоборот, увеличивает случайность и делает ответы более разнообразными.

```
Temperature = 1.5
→ больше разнообразный ответ
```

Технически temperature изменяет распределение вероятностей токенов.

$$
P_i=\frac{e^{z_i/T}}{\sum_j e^{z_j/T}}
$$

Где:

$$T$$ → temperature

$$z$$ → logits модели

Чем выше температура, тем более "размазанными" становятся вероятности токенов.

### Почему это важно

Для production AI-систем слишком высокая случайность может быть опасной.

Особенно в задачах, где нужна точность и предсказуемость:

```
• SQL generation
• Financial systems
• AI agents with tools
• Infrastructure automation
```

В таких системах обычно нужен более deterministic behavior, чтобы модель не генерировала неожиданные действия или ошибки.

***

## Top-p Sampling

Top-p — это ещё один способ контролировать генерацию.

Вместо выбора из всех возможных токенов модель ограничивается только наиболее вероятными вариантами.

Например:

```
top-p = 0.9
```

означает:

```
Берём только те токены,
чья суммарная вероятность достигает 90%.
```

Это помогает убрать слишком маловероятные и случайные варианты ответа.

***

## Production Guidelines

На практике для разных задач используют разные значения temperature:

```
Code Generation   → 0.1 – 0.3
SQL               → 0.0 – 0.2
Creative Writing  → 0.8 – 1.2
AI Agents         → 0.2 – 0.5
```

Чем более критична точность системы, тем ниже обычно ставят temperature.

Низкая temperature:

```
0.1
```

– более deterministic output.

\
Высокая:

```
1.5
```

– больше randomness.
