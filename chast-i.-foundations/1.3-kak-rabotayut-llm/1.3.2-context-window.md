# 1.3.2 Context Window

Context window – это "оперативная память" модели.

Модель не помнит весь интернет и не хранит ваш диалог целиком. Она видит только текущее окно контекста.

Если контекст переполнен:

* старые сообщения выпадают
* инструкции теряются
* рассуждения (reasoning) деградируют
* растёт стоимость inference

### Почему context window – это архитектурная проблема

Для AI-agents context management становится отдельной инженерной задачей.

Например:

* что хранить в памяти?
* что суммаризировать?
* что выбрасывать?
* что отправлять повторно?
* как делать retrieval?

Это уже не prompt engineering.

Это distributed systems engineering.

***

### Context stuffing

Одна из самых распространённых ошибок:

```
"Давайте отправим в модель вообще всё."
```

На практике это ухудшает качество.

Почему?

Потому что attention размазывается по огромному количеству токенов.

***

### Attention complexity

Классический transformer имеет сложность:

O(n^2)

где:

* n – количество токенов.

Если context window увеличивается в 10 раз:

* вычисления растут примерно в 100 раз.

Именно поэтому inference для giant contexts настолько дорогой.
