# 1.3.3 Attention – интуитивно

Внимание (аttention) – это механизм, который позволяет модели понимать: на какие части текста нужно смотреть сильнее.

Когда человек читает:

```
"PHP developer fixed the bug because he understood the architecture."
```

человек автоматически понимает, что "he" относится к developer.

Трансформер (transformer) делает примерно то же самое через математические веса внимания.

### Показатель внимания - Attention score

Упрощённо attention можно представить как:

$$
Attention(Q,K,V)=softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V
$$

Это выглядит страшно, но идея очень простая:

* Query – что мы ищем
* Key – где искать
* Value – что извлекать

### Интуитивная аналогия

Представьте IDE в котором вы работаете.

Когда вы пишете:

```php
$user->
```

IDE начинает искать:

* методы
* свойства
* типы
* контекст

и в конце концов показывает вам подсказки.

Attention делает похожую вещь, только внутри нейросети.

### Почему трансформеры изменили разработку программного обеспечения

До трансформеров NLP был очень ограниченным:

* плохое понимание контекста
* слабая генерация
* отсутствие долгосрочных зависимостей

Трансформенная архитектура позволила:

* массовую параллелизацию
* масштабирование на гигантские датасеты
* обучение на интернете
* новые возможности

После этого разработка программного обеспечения начал меняться радикально.

### Что изменилось практически

LLM впервые позволили:

* генерировать production-like код
* работать с документацией
* автоматизировать использование шаблонного кода
* создавать ИИ-пилотов
* строить ИИ-агентов

По сути, трансформеры стали новым исполнительным уровнем экосистемы программного обеспечения.
