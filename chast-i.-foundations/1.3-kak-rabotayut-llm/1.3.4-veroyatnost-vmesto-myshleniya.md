# 1.3.4 Вероятность вместо "мышления"

### Как работает LLM

Самое главное, что нужно понимать инженеру: LLM не думает как человек.

Модель не обладает сознанием, пониманием или настоящим мышлением. Вместо этого она постоянно вычисляет вероятности и пытается предсказать, какой токен должен идти следующим.

#### Пример

То есть на каждом шаге модель фактически отвечает на один вопрос:

```
Какой токен наиболее вероятен следующим?
```

Например, если prompt выглядит так:

```
The capital of France is
```

то модель анализирует огромное количество статистических связей из обучающих данных. В результате получает примерно следующее:

| Token  | Probability |
| ------ | ----------- |
| Paris  | 0.91        |
| Lyon   | 0.03        |
| London | 0.01        |

Отсюда она приходит к выводу, что следующим токеном с высокой вероятностью будет

```
Paris
```

После этого специальный [sampling algorithm](../../vvedenie/glossarii.md#sampling-algorithm) выбирает итоговый токен из набора возможных вариантов.

## Цепочка мыслей (chain-of-thought)

Когда кажется, что модель "рассуждает", на самом деле она не думает в человеческом смысле.

Она просто генерирует последовательность токенов, которая статистически похожа на процесс рассуждения.

Например:

```
Question
   ↓
Generate next token
   ↓
Generate next token
   ↓
Generate next token
   ↓
Reasoning-like output
```

Из-за этого ответы модели могут выглядеть как логическое размышление, хотя внутри происходит только последовательное предсказание токенов.

Именно поэтому важно понимать разницу между настоящим мышлением и генерацией статистического текста.

## Возникающее поведение (emergent behavior)

При этом у больших моделей появляется интересный эффект.

Когда размер модели и объём данных сильно растут, возникают способности, которые никто явно не программировал:

* Рассуждения
* Планирование
* Генерация кода
* Использование инструментов
* Многоязычное понимание

Это явление называют emergent behavior.

Самое удивительное, что исследователи до сих пор не могут полностью объяснить, почему такие способности появляются автоматически при масштабировании моделей.
