# 1.3 Как работают LLM

Когда разработчик впервые сталкивается с LLM (Large Language Models), возникает ощущение магии. Модель пишет код, объясняет архитектуру, отвечает на вопросы, переводит, генерирует SQL, делает summary документации и даже поддерживает диалог. Создаётся впечатление, что внутри действительно есть "мышление".

Но если посмотреть глубже, окажется, что LLM – это огромная вероятностная система (probabilistic system), построенная вокруг одной фундаментальной задачи:

> предсказать следующий токен.

Именно вокруг этой идеи строится почти всё современное AI-приложение – от ChatGPT до AI-агентов и автономных систем.

В этой главе мы разберём, как работают современные LLM-модели, почему transformers перевернули software engineering и почему production AI-системы обязаны быть deterministic поверх probabilistic models.
