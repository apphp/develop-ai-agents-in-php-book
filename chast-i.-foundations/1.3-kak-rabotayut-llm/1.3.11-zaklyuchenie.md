# 1.3.11 Заключение

Современные LLM – это не "искусственный мозг" и не магия.

Это большие вероятностные системы, построенные на предсказании токенов, механизмы внимания в архитектуре трансформеров, эмбеддинги и статистическое языковое моделирование.

Однако именно сочетание нескольких факторов – огромного масштаба моделей, архитектуры трансформеров и огромных массивов обучающих данных – привело к появлению AI-систем, которые начали радикально менять разработку программного обеспечения.

Для бэкенд-разработчика важно понимать ключевую вещь: product-системы AI – это не только сама модель.

На практике основную роль играет инфраструктура и архитектура вокруг LLM. Именно они делают систему надёжной, управляемой и пригодной для реального использования.

В product-системах AI-системах критически важны:

* управление контекстом
* извлечение данных
* память
* проверка
* оркестрация
* детерминированное выполнение
* наблюдаемость
* контроль затрат

Поэтому современная разработка AI – это не просто работа с промптами или вызов API модели. Это построение полноценной системы, где LLM становится лишь одним из компонентов общей архитектуры.
