# 1.2.9 Сквозной проект книги

### Контекст проекта

На протяжении книги мы с вами будем строить полноценную AI Operations Platform (или **AIOps**) - платформу искусственного интеллекта для ИТ-операций.

Этот проект станет общим практическим примером для следующих глав:

* Подключение LLM к PHP
* AI gateway
* AI-агенты
* memory layer
* embeddings
* vector search
* orchestration
* observability
* tool calling
* multi-agent workflows

Это будет не toy-проект и не простой chatbot поверх OpenAI API. Мы будем постепенно проектировать production-oriented AI system с агентами, orchestration engine, memory layer, vector search, observability и event-driven архитектурой.

Финальная система будет включать AI agents, long-running workflows, queues, RAG, multi-provider поддержку моделей и tool execution.

Архитектурно проект будет выглядеть примерно так:

```
Frontend
    ↓
PHP API Platform
    ↓
AI Orchestrator
    ↓
Agent Runtime
    ↓
Tools / Memory / RAG
    ↓
LLM Providers
```

По мере чтения книги цель будет не только изучить отдельные AI-технологии, но и сформировать полноценное инженерное понимание того, как строятся современные AI-системы.

Потому что роль бэкенд-инженера постепенно меняется.

Сегодня разработчик уже не просто пишет бизнес-логику. Всё чаще он становится AI Systems Engineer — инженером, который проектирует reasoning pipelines, orchestration architecture и инфраструктуру для интеллектуальных систем.

И в этой новой реальности PHP оказывается гораздо сильнее, чем многие привыкли думать.

Потому что AI-революция — это не только сами модели.

Большая часть реальной работы связана с инфраструктурой, orchestration, distributed systems, интеграциями и production engineering.

А бэкенд-разработка всегда строилась именно вокруг этих задач.

### Сценарий

Представим SaaS-платформу поддержки клиентов.

Система получает:

* email
* support tickets
* сообщения из чатов
* комментарии пользователей
* обращения из CRM

Компания хочет автоматически:

* анализировать тональность
* извлекать проблемы
* определять urgency
* генерировать summary
* предлагать ответ оператору

### Почему выбран именно этот сквозной проект

Этот сценарий почти идеально подходит для этой книги.

Он включает:

* высокую нагрузку
* AI inference
* очереди
* realtime UX
* structured output
* retries
* observability
* multi-provider routing
* AI workflows

И самое главное – проект выглядит реалистично и очень похож на настоящие production-системы.
