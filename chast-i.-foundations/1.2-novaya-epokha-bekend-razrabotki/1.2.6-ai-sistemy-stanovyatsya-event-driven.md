# 1.2.6 AI-системы становятся event-driven

Современные AI-платформы всё чаще строятся по событийной (event-driven) архитектуре.

Дело в том, что обычная модель request-response, где система сразу отвечает на запрос пользователя, плохо подходит для сложных AI-процессов. Многие операции в AI занимают заметное время. Например, распознавание текста из документов, создание эмбеддингов, индексация данных, суммаризация или классификация контента.

Из-за этого AI-системы обычно разбивают работу на отдельные этапы, которые выполняются последовательно как цепочка событий.

Например, пользователь загружает документ. После этого запускается процесс OCR (Optical Character Recognition) для распознавания текста. Затем система создаёт эмбеддинги, индексирует данные для поиска, делает краткое summary документа и только потом выполняет классификацию.

```
User Uploads Document
        ↓
OCR Event
        ↓
Embedding Generation
        ↓
Vector Indexing
        ↓
Summarization
        ↓
Classification
```

Такой подход делает систему более гибкой и масштабируемой. Каждый этап может работать независимо от остальных, запускаться через очереди и масштабироваться отдельно под нагрузку.

В результате AI-платформа превращается не в один большой сервис, а в набор связанных между собой процессов и событий.
