# 1.4.7 Надёжное выполнение задач

Durable execution – надёжное выполнение задач. Это одна из самых недооценённых тем в разработке AI-систем.

Операции с языковыми моделями могут занимать:

* минуты
* часы
* иногда даже дни

Особенно если система:

* проводит исследование
* взаимодействует с людьми
* ожидает согласования
* обращается к внешним сервисам через API

### Почему обычная схема запрос–ответ не подходит

Классический жизненный цикл HTTP-запроса слишком короткий для таких задач.

AI-системам часто необходимы:

* приостановка и продолжение выполнения
* повторные попытки
* точки сохранения
* восстановление после сбоев

### Системы надёжного выполнения

Для этого используют специальные механизмы управления длительными процессами.

Популярные подходы:

* Temporal
* LangGraph
* событийная архитектура
* движки управления рабочими процессами

#### Пример устойчивого процесса

1. Агент начал работу.
2. Вызов инструмента завершился ошибкой.
3. Состояние системы сохранилось.
4. Процесс был перезапущен.
5. Выполнение продолжилось с точки сохранения.

#### PHP и длительные процессы

PHP исторически ориентирован на короткие запросы и быстрый ответ клиенту.

Но современные AI-системы на PHP обычно используют:

* очереди задач
* Kafka
* Redis Streams
* RoadRunner
* Swoole
* движки рабочих процессов

#### Пример обработки задачи через очередь

```php
class AIJob
{
    public function handle(): void
    {
        $result = $this->callLLM();

        if (!$result) {
            $this->retry();
            return;
        }

        $this->save($result);
    }

    private function retry(): void
    {
        echo "Retry scheduled";
    }
}
```

В этом примере задача обращается к языковой модели.\
Если запрос завершается неудачно, система планирует повторную попытку вместо немедленного завершения процесса.
