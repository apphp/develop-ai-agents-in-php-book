# 1.4.10 Anti-patterns AI systems

Разработка систем на основе искусственного интеллекта развивается очень быстро, поэтому неудачные подходы и типичные ошибки появляются постоянно.

### "LLM решит всё"

Это одна из самых распространённых ошибок.

Языковая модель не заменяет:

* архитектуру системы
* проверку данных и результатов
* бизнес-логику
* мониторинг и контроль работы системы
* безопасность

Даже сильная модель сама по себе не делает систему надёжной.

### Бесконечные циклы агентов

Классическая проблема агентных систем:

* бесконечные повторные попытки
* постоянное "переосмысление" ответа
* неконтролируемое планирование действий

В результате система может зациклиться и начать тратить ресурсы без реального прогресса.

### Отсутствие сохранения состояния

Если текущее состояние выполнения нигде не хранится, система становится очень хрупкой.

Любой сбой означает потерю всего процесса и необходимость начинать заново.

### Чрезмерное использование агентов

Многим задачам агент вообще не нужен.

Иногда хорошая AI-система выглядит так:

```
User Input
↓
Prompt Template
↓
LLM
↓
Structured Output
↓
Save Result
```

И всё. Этого вполне достаточно.

#### "Спагетти" из промптов

Когда вся логика работы системы существует только внутри запросов к модели, проект очень быстро становится неуправляемым.

Например:

```
If tool A failed do B unless C happened before D...
```

Это уже не инженерия, а хаос.
